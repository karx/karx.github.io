# kaaroCatalogue

[GitHub Repo ↗](https://github.com/karx/kaaroCatalogue)

kaaroCatalogue is a project dedicated to the systematic creation of personal lists and indexes. It serves as a laboratory for exploring how platform APIs (like YouTube) can be used to harvest, validate, and structure information that is usually scattered and noisy.

## Active Catalogues

- [[Gemini - Global Standup Comedy Index|The Global Standup Comedy Index]]
- [[Gemini Indian Kavi Index|Indian Kavi Index]]

## Philosophy

The project is driven by the need for "High-Signal" lists—moving away from algorithmic recommendations toward curated, queryable archives of personal and cultural value.
