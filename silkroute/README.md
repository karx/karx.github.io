# SilkRoute

> A hyperlocal economy where skill meets community need.  
> These charters are the product. Any locality can adopt them.

---

## Charters

| Charter | Purpose |
|---|---|
| [Community](community.md) | What SilkRoute is. Values and founding principles. |
| [Member](member.md) | Who can join. Rights and responsibilities. |
| [Work](work.md) | How jobs are posted, claimed, completed, and verified. |
| [Token](token.md) | How SilkCoins work. Earning, spending, cashing out. |
| [Shared Fund](shared-fund.md) | How the community pool is fed, governed, and spent. |
| [Governance](governance.md) | How decisions are made. Proposals, voting, thresholds. |
| [Vendor](vendor.md) | How local businesses participate without capturing the community. |

---

## How to adopt this in your locality

1. Read all seven charters
2. Convene a founding group (minimum 5 members)
3. Agree on your locality's specific parameters (token rate, fund %, dispute process)
4. Record your parameters in a `local.md` file
5. Begin with one work item
